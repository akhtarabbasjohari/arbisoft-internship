# Arbisoft Internship 2026

This repository contains my work for the Arbisoft AI Focused Remote Internship Program 2026.

## Structure

arbisoft-internship/
  frontend/     Next.js frontend (Week 1)
  backend/      Django backend (Week 2, in progress)

Each week's work is done on a separate branch (for example week-1-frontend) and merged into main once the week's tasks are complete and verified.
